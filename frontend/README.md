# Frontend 开发文档

## 1. 前端目标
前端负责把 Smart Memo 变成一个“适合个人使用”的智能记忆界面，重点让用户可以轻松完成资料上传、生成背诵任务、答题回忆和复习反馈。

## 2. 推荐技术栈
- Next.js 14+（推荐，适合做个人产品）
- TypeScript
- Tailwind CSS
- Axios 或 Fetch 封装
- Zustand / React Query（可选）
- React Hook Form（可选）

> 如果你想先快速启动，可以先用 React + Vite；但从长期维护角度，Next.js 更适合做一个完整且好看的个人工具。

## 3. 目录建议
```text
frontend/
  app/               # Next.js 页面
  components/        # 可复用组件
  lib/               # 工具函数与 API 客户端
  hooks/             # 自定义 Hook
  store/             # 状态管理
  styles/            # 全局样式
  public/            # 静态资源
```

## 4. 页面设计建议
### 4.1 首页
- 介绍工具定位
- 提供“开始使用”的入口

### 4.2 上传页面
- 支持上传学习资料
- 展示上传状态与文件信息

### 4.3 生成任务页面
- 展示背诵题、填空题、问答题
- 支持答题与提交

### 4.4 复习结果页面
- 展示回答结果
- 提供复习和再次生成的入口

## 5. 前端开发流程
1. 先完成页面结构与路由
2. 再接入后端接口和数据流
3. 最后补充交互反馈与状态管理

## 6. 数据流与状态管理
- 前端通过统一 API 客户端和后端通信
- 如果页面比较复杂，可以使用 Zustand 或 React Query
- 所有接口请求最好封装到统一模块中，避免散落在组件中

## 7. UI 规范建议
- 采用简洁、轻量、偏个人使用的视觉风格
- 强调“上传 → 生成 → 回答 → 复习”的主流程
- 适配桌面端和移动端

## 8. 开发阶段安排
### Phase 1
- 初始化 Next.js / React 项目
- 完成基础布局与路由

### Phase 2
- 接入上传页面与接口联调
- 完成题目展示与答题流程

### Phase 3
- 增加结果页、历史记录和复习优化
- 优化加载状态与错误提示

## 9. 质量要求
- 页面交互要顺滑，避免卡顿
- 接口异常要给出明确提示
- 重点流程尽量保证可用性和可维护性

## 10. 推荐启动命令
```bash
npm install
npm run dev
```
