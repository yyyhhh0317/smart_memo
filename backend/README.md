# Backend 开发文档

## 1. 后端目标
后端负责承接 Smart Memo 的核心能力，重点是让“个人用户”能够自己配置模型、上传内容、生成背诵任务，并在本地安全使用。

## 2. 适合的技术栈
- Python 3.11+
- FastAPI
- Pydantic
- SQLAlchemy / SQLModel
- Alembic（可选）
- Uvicorn
- SQLite（默认）
- Redis（可选，用于异步任务）

## 3. 目录建议
```text
backend/
  app/
    api/              # 路由与接口层
    core/             # 配置、环境变量、日志、异常处理
    models/           # 数据模型
    schemas/          # 请求/响应 Schema
    services/         # 业务服务
    utils/            # 工具函数
    deps/             # 依赖注入
  tests/             # 测试代码
  requirements.txt
  .env.example
```

## 4. 核心模块设计
### 4.1 配置管理
- 支持从环境变量读取模型地址、API Key、模型名称
- 兼容 OpenAI 风格接口，也方便接入其他厂商
- 所有敏感信息不写死在代码里

### 4.2 资料上传与解析
- 接收文本、Word、PDF、PPT、图片等内容
- 先做内容清洗，再交给模型生成背诵任务
- 适合个人本地使用，避免复杂的服务依赖

### 4.3 题目生成服务
- 根据内容生成背诵题、填空题、问答题、复述提示
- 所有输出尽量保持结构化 JSON
- 生成前增加上下文边界约束，减少幻觉

### 4.4 本地数据管理
- 保存用户资料、题目记录、回答结果、复习历史
- 默认使用 SQLite，方便直接本地运行

## 5. API 设计建议
- 采用 REST 风格接口
- 统一响应结构：
```json
{
  "success": true,
  "data": {},
  "error": null
}
```
- 统一错误码：
  - 400：参数错误
  - 401：未授权
  - 404：资源不存在
  - 500：服务器内部错误

## 6. 开发流程建议
1. 先定义接口 Schema
2. 再实现服务层逻辑
3. 再连接数据库模型
4. 最后补上测试与异常处理

## 7. 开发阶段安排
### Phase 1
- 初始化 FastAPI 项目
- 完成健康检查接口
- 完成环境变量配置读取

### Phase 2
- 完成文件上传接口
- 接入内容解析与清洗逻辑
- 完成题目生成接口

### Phase 3
- 完成答题记录与历史查询
- 支持复习模式与记忆进度展示
- 增强错误处理与日志能力

## 8. 质量要求
- 所有核心接口尽量有测试覆盖
- 大模型调用要有超时、重试与错误兜底
- 生成结果应尽量可控，避免无边界输出

## 9. 推荐启动命令
```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```
