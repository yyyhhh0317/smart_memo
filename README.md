# Smart Memo - 个人智能记忆系统

## 1. 项目定位
Smart Memo 现在将定位为一个“面向个人使用的智能记忆与背诵工具”。

它的目标不是做一个多人协作 SaaS，而是让任何人把代码从 GitHub 拉下来后，自己配置自己的大模型 API，然后把它变成一个真正属于自己的智能学习助手。

## 2. 设计目标
- 以“自用”为核心，强调简单、轻量、可控
- 支持用户上传自己的学习资料
- 自动生成背诵、填空、问答、复习任务
- 重点保护隐私，数据默认本地管理
- 代码开源，模型能力由用户自己接入

## 3. 适合的使用方式
用户可以这样使用：
1. 从 GitHub 拉取项目源码
2. 配置自己的模型服务地址和 API Key
3. 启动前后端服务
4. 上传资料，开始智能背诵与复习

## 4. 技术栈建议
- 后端：Python + FastAPI
- 前端：Next.js 14+（推荐）或 React + Vite
- 数据库：SQLite，适合个人使用
- 模型接入：支持 OpenAI 兼容接口、DeepSeek、通义、SiliconFlow 等
- 配置方式：通过环境变量管理 API Key、模型名称、地址等

## 5. 项目结构
```text
smart_memo/
  README.md
  backend/
  frontend/
```

## 6. 核心模块
- 资料上传与解析
- 知识内容清洗与结构化
- AI 生成背诵题、填空题、问答题
- 复习记录与记忆进度管理
- 用户自定义模型配置

## 7. 开源发布原则
- 代码保持开源，便于别人学习和二次开发
- 不把敏感密钥写死在代码中
- 所有模型配置通过环境变量或配置文件管理
- 尽量避免绑定特定云服务商，便于切换模型提供方

## 8. 开发阶段建议
### Phase 1：个人可用 MVP
- 搭建基本前后端工程
- 支持上传文本资料
- 支持调用自定义 LLM 生成题目

### Phase 2：复习体验优化
- 增加背诵、填空、问答流程
- 支持历史记录和复习进度

### Phase 3：个性化能力增强
- 支持不同记忆策略
- 支持更强的内容结构化能力
- 支持本地化和私有化部署

## 9. 适合的产品定位
这不是一个面向大众的商业产品，而是一个“个人知识管理 + AI 记忆助手”的轻量工具。它更像是：
- 你自己的学习外挂
- 你自己的知识复习助手
- 你自己的私有化 AI 工具

## 10. 目标用户
- 希望把知识变成可复习内容的人
- 想自己控制模型配置的人
- 希望把项目做成开源作品并长期维护的人
